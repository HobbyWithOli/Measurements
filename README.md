# Saturday Tape Log

Weekly tape-measure log: waist, hips, chest, shoulders, neck, arms, thighs, calves and weight, with week-on-week and 4-week changes, trend lines, and a US Navy body fat estimate.

Install: open the GitHub Pages URL on your phone and choose **Add to Home Screen**. Works offline. Data is stored only on the device; use **Copy backup link** to keep a restore link.
